# devlog — 项目开发日志

本目录存储「欧几里德之门」项目的定期整体评估报告，记录项目状态快照、问题发现与决策记录。

## 命名规范

```
YYYY-MM-DD_主题_v{版本号}.md
```

示例：`2026-08-02_项目整体评估_v1.md`

版本号规则与 archive 一致：对已有报告进行修订时递增，旧版移入本目录并以 `_v{n}` 后缀保留。

## 报告结构模板

每篇评估报告按以下结构组织：

1. **评估范围** — 本次评估了什么（文件/系统/维度）
2. **项目快照** — 评估时的项目状态（文章数、技能版本、git 状态）
3. **发现（分级）** — 按 P0（紧急）/ P1（重要）/ P2（一般）分级
4. **亮点** — 值得保留的设计与实践
5. **决策记录** — 本次评估中用户拍板的事项
6. **行动项** — 由发现派生出的待办，完成后回勾

## 安全约定

报告中**禁止写入任何 API 密钥明文**。提及密钥时只写服务名称与位置。

## 频率

建议在以下时机产出报告：
- 阶段性里程碑（如每 5 篇文章、工作流大版本升级）
- 大型重构前后
- 环境迁移后（如切换 AI 平台/模型）
